# 🌐 «Мои подписки» — версия для GitHub Pages

Это статическая версия сайта для бесплатного размещения на **GitHub Pages**.
Вы получите публичную ссылку вида `https://ваш-username.github.io/podpiski/`.

## 📦 Что в этой папке

| Файл | Зачем |
|---|---|
| `index.html` | Страница сайта |
| `styles.css` | Тёмная неоновая тема + анимации |
| `app.js` | Логика сайта |
| `parser.js` | Разбор фраз («иви через 30 дней») |
| `.nojekyll` | Служебный файл (не трогать) |

> ⚠️ **Не загружайте** `server.js`, `config.json`, `data.json` и `start.cmd` в репозиторий.
> В `config.json` лежит **секретный токен бота** — если он попадёт в публичный репозиторий, ботом смогут управлять другие люди.

## 🚀 Пошаговая загрузка (всё через браузер, без команд)

### Шаг 1. Аккаунт GitHub
1. Откройте https://github.com
2. Если нет аккаунта — **Sign up** (регистрация по e-mail).

### Шаг 2. Создать репозиторий
1. В правом верхнем углу нажмите **+** → **New repository**.
2. В поле **Repository name** напишите: `podpiski`
3. Оставьте **Public** (для бесплатных Pages нужен Public).
4. Нажмите **Create repository**.

### Шаг 3. Загрузить файлы
1. На странице нового репозитория нажмите **Add file** → **Upload files**.
2. Перетащите туда **все 5 файлов** из этой папки (или выберите через «choose your files»).
3. Внизу нажмите **Commit changes**.

### Шаг 4. Включить GitHub Pages
1. Откройте вкладку **Settings** (вверху справа).
2. Слева в меню выберите **Pages**.
3. В блоке **Build and deployment**:
   - **Source** → `Deploy from a branch`
   - **Branch** → `main`, папка → `/ (root)`
   - Нажмите **Save**.
4. Подождите **1–2 минуты**.

### Шаг 5. Готово 🎉
1. Снова откройте **Settings → Pages** — там появится ссылка:
   `https://ваш-username.github.io/podpiski/`
2. Откройте её — сайт работает!

## ✅ Что работает на GitHub Pages

- Список подписок, календарь, добавление свободным текстом («иви через 30 дней»)
- Данные хранятся в браузере (localStorage)
- Настройки, ручной ввод chat_id, тестовое сообщение в Telegram
- Напоминания в Telegram **пока вкладка сайта открыта** (отправляются напрямую из браузера)

## ❌ Что НЕ работает на GitHub Pages

GitHub Pages не умеет запускать `server.js`, поэтому:
- бот не отвечает в чате (`/start`, `/list`),
- каталог сервисов и оплата Stars,
- фоновые напоминания, когда сайт **закрыт**.

Для полной версии нужен Node-хостинг (Render / Railway / Fly.io) — это отдельная инструкция.

## 🔑 Как узнать свой chat_id (для Telegram)

1. В Telegram откройте **@userinfobot** → **Start**.
2. Он пришлёт `Your ID: 123456789`.
3. На сайте: **⚙️ Настройки** → вставьте число в поле **Chat ID** → **Сохранить**.
